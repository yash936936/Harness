# Component: memory

> Area type: bundle. Location: `src/bundles/memory/`. Hand-written sections describe the service and its invariants; the files-and-exports block is generated by `npm run docs:components`.

## Purpose

Composes the episodic and hot memory tiers behind `ctx.memory`. It records one log-linked episode per agent turn, provides actor-scoped read views, injects the hot tier into agent prompts, and runs deterministic lesson compaction. The optional semantic tier is a separate service and is attached only when embedding and vector-store dependencies are configured.

## Route (how control reaches it)

`profile-coding` installs `Memory` after `log`, `egress`, and `agentLoop`. The service is registered as `ctx.memory`; it composes `EpisodicMemory`, `HotTier`, `MemoryAccess`, and `Compaction`. `runTurn` delegates to `ctx.agentLoop.run`, then records the turn's session-log sequence range as an episode. When configured, `MemorySemantic` is installed separately and attached through `ctx.memory.setSemanticService`. Sub-agent reads use `ctx.memory.view(actor)` and require a live grant.

## Config surface and invariants

- `path` selects persistent episodic and hot-tier storage. Without it, memory remains in process.
- `maxFieldChars` bounds stored episode fields; `hotTokenCap` bounds the rendered hot tier.
- `deriveLessons` defaults to false. When enabled, lessons are templated only from harness facts in the session log, never model or file text.
- `injectHot` defaults to true. The hot tier is added as a system section at order 10.
- `compaction.everyTurns`, when set, must be a positive safe integer. Compaction errors are recorded in `lastCompaction` and do not fail the user's turn.
- Episodic writes are idempotent by `sessionId:fromSeq`; records are linked to their source log sequence range and registered secrets are redacted before storage and return.
- Scoped actors with no live memory grant fail closed. Their episode queries are forced to their own actor ID.

## Known limits

- Episodic memory is a record of turns, not evidence that a real model learns from it.
- The semantic tier is optional and depends on embeddings plus a vector store. Its presence does not prove live retrieval quality.
- The token estimate defaults to `ceil(chars / 3)`; there is no tokenizer in this project.
- Compaction uses deterministic templates and configured thresholds, not a model-generated summary.
