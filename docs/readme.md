# Coding Harness

A multi-agent orchestration harness for coding tasks, built on Cordis. Every
capability — model access, tools, retrieval, memory, sandboxing, the
browser — is a swappable plugin ("bundle"); profiles compose bundles into
runnable stacks from a single-agent smoke-test kernel up to a governed,
multi-agent, multi-user system.
